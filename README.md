# Ironwood Contracting — Website Demo

Ironwood Contracting is a fictional general-contractor and home-improvement brand created by **Glanzberg Web** as a portfolio demonstration.

This concept shows how a contractor website can combine project photography, service positioning, trust signals, process clarity, and a strong estimate-request flow in a polished responsive experience.

## Demo highlights

- Responsive contractor / home-improvement website
- Project-first visual design
- Remodeling, renovation, and exterior service sections
- Featured project gallery
- Trust, warranty, and process sections
- Estimate-request form demonstration
- Static structure ready for GitHub Pages

## Important

Ironwood Contracting is not a real business. Names, testimonials, project details, licensing references, warranties, statistics, phone numbers, addresses, and service information are sample content used solely for demonstration.

The estimate form is intentionally configured as a demo and does not send information to a real contractor.

## Photography

Demo photography is loaded from Unsplash-hosted image URLs and is used only as visual presentation material for this fictional portfolio concept.
